# Study on LLMs use for Early-Stage User Needs Interpretation

This repository contains an AI/ML pipeline for a study on the implications of conducting an early-stage user needs interpretation using LLMs/AI agents. 

The walkthrough scenario is wood crafting in an engineering makerspace across three gender personas: man, woman, and neutral gender. Prompting of AI agents was done via an API, and the models' responses were extracted and recorded for both quantitative and qualitative analysis.

---

## Experimental Setup

The repository utilizes a controlled scenario where everything about the scenario was the same except for referring to the users with gender pronouns:
* **Man:** He/him
* **Woman:** She/her
* **Neutral Gender:** They/them

---

## Core Notebook (`makerspace_llm_api_prompting.ipynb`)

This file contains the structure and code for prompting **5 different LLMs** on the makerspace project scenario. Under each user persona, the AI agents were prompted to perform the following:
1. Extract all observed pain points for each user.
2. Provide severity ratings for those pain points.
3. Answer follow-up perceptive questions asked for each user.

---

## Data Analysis

Responses from these prompts were stored and the extracted data was saved for further analysis, which includes:
* Assessing the severity ratings across the genders and models.
* Assessing the models' performance in accurately recalling the pain points (precision) and in recalling all pain points present in the study (recall) 
* Performing cosine similarity on the qualitative response data generated by the models.
* Performing sentiment analysis on the qualitative response data generated by the models.
* Comparing these metrics across the gender personas.
* Conducting statistical test in R (ANOVA/Kruskal-Wallis) to assess the impact of IVs (gender condition, models, questions) on DVs (recalled pain points, severity ratings, perception ratings, cosine similarity scores, sentiment scores, computational SCM scores)
